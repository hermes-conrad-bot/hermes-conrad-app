# Hermes Conrad (personal assistant)

Hermes Conrad is a personal, single-user AI assistant run by its owner on a private, self-hosted server. It helps the owner with everyday tasks such as meal planning and scheduling.

To do this it asks for permission to access the owner's own Google account:

- **Google Calendar**: read and manage the owner's calendar events.
- **Gmail (read-only)**: read the owner's email, to find information relevant to tasks such as scheduling and planning. It cannot send, delete, or modify email.

The app is not offered to the public and has exactly one user: its owner. See [PRIVACY.md](PRIVACY.md) for how data is handled.
